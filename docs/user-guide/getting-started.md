# Getting Started

## Tujuan

Dashboard ini menjadi pusat analisis data perusahaan, status sistem, dan integrasi Analysis API untuk chatbot.

## Langkah awal

1. Login dengan akun Anda.
2. Buka `Dashboard`.
3. Periksa `Data Connections` dan `AI Providers`.
4. Pilih modul bisnis yang ingin ditinjau.

## Catatan penting

- Badge `data_mapping_incomplete` berarti query final belum divalidasi penuh terhadap sumber produksi.
- Semua koneksi harus diuji read-only sebelum dipakai untuk analisis rutin.
