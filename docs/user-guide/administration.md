# Administration

## Data Connections

- Tambah koneksi per sistem.
- Simpan host, database, username, dan nama env key password.
- Jalankan `Test` untuk menguji koneksi dan validasi read-only.

## AI Providers

- Atur provider aktif, model, base URL, timeout, dan prioritas.
- Jalankan `Health Test` untuk melihat kesiapan provider.

## Users and Roles

- Pengguna baru otomatis menjadi `Viewer`.
- Penyesuaian role lanjutan dilakukan oleh admin.
